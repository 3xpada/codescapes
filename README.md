# Codescapes

Codescapes is a Flutter puzzle game with Python, Java, C#, and C worlds.
Each language world contains ten ordered levels, progressing from basic output
and variables through loops, calculations, and nested loops. Players complete
short fill-in-the-blank programs, earn 5 coins for each first clear, and spend
coins on hints. The Java, C#, and C worlds run beginner console programs,
variables, and incrementing `for` loops through safe subset interpreters; they
do not compile arbitrary native source.
Gameplay includes a softly looping original soundtrack and tap, hint, success,
and error sounds. Music and sound effects can be enabled independently in
Settings, and those choices are saved on the device.
A local player profile stores a username and displays coin and puzzle progress.
Persistent achievements track puzzle clears, language mastery, hints, and
lifetime coins earned.

## Getting Started

Run the app with Flutter:

```sh
flutter pub get
flutter run
```

Run the tests with `flutter test`.
